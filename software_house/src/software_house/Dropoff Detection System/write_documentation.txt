## Visão Geral do Projeto

O **Dropoff Detection System** é uma aplicação web que tem como objetivo validar se um pacote foi entregue no local correto. A aplicação permite que o usuário insira uma descrição do local e carregue uma imagem do mesmo, utilizando um modelo de linguagem para realizar a validação entre eles.

## Arquitetura do Software

### Diagrama UML

```plaintext
+---------------------+      +---------------------+
|  Frontend (React)   | <--->|   Backend (FastAPI) |
+---------------------+      +---------------------+
       |      ^                        |
       |      |                        |
       |      +------------------------+
       |                       |
+---------------------+      +---------------------+
|  OpenAI API        |      |  Banco de Dados     |
|  (gpt-4o, API)     |      |  (se necessário)    |
+---------------------+      +---------------------+
```

### Componentes Principais

- **Frontend**:
  - Criado em **React.js** para interação do usuário.
  - Caixa de texto para descrição, upload de imagem, visualização da imagem e validação.

- **Backend**:
  - Construído em **FastAPI** usando Python.
  - Recebe descrição e imagem, processa e chama a API da OpenAI para validação.
  
- **OpenAI API**:
  - Utiliza o modelo **gpt-4o** para determinar se a descrição e a imagem são compatíveis.

## Guia de Instalação e Configuração

1. **Configurar o Ambiente Backend**:
   - Instalar as dependências:
   ```bash
   pip install fastapi uvicorn openai python-dotenv
   ```

2. **Configurar o Ambiente Frontend**:
   - Criar a aplicação React:
   ```bash
   npx create-react-app frontend
   cd frontend
   ```

3. **Executar o Backend**:
   - Rodar o servidor FastAPI:
   ```bash
   uvicorn main:app --reload
   ```

4. **Executar o Frontend**:
   - Iniciar o servidor React:
   ```bash
   npm start
   ```

## Documentação da API

### Endpoint de Validação

- **Método**: POST  
- **URL**: `/validate/`  

#### Request Body
```json
{
    "description": "A descrição do local onde o pacote foi deixado",
    "image": "Imagem codificada em base64"
}
```

#### Response
```json
{
    "answer": "Valid" ou "Invalid",
    "reasoning": "Detalhes do raciocínio utilizado para a análise."
}
```

## Guia do Usuário

### Passo a Passo para Uso da Aplicação

1. **Acessar a Aplicação**: Abra o navegador e acesse a interface da aplicação.
2. **Inserir Descrição**: Na caixa de texto, insira a descrição do local onde o pacote foi deixado.
3. **Carregar Imagem**: Utilize o botão de upload para carregar uma imagem do local.
4. **Executar Validação**: Clique no botão "Validate" para verificar se a descrição corresponde à imagem carregada.
5. **Visualizar Resultados**: O resultado será exibido como 'Valid' ou 'Invalid', e você pode clicar em "Show Reasoning" para entender a análise realizada.

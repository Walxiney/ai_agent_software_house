**Backlog Detalhado para o Projeto: Dropoff Detection System**

---

### Visão Geral do Escopo do Projeto:
O Dropoff Detection System é uma aplicação web destinada a validar se um pacote foi entregue no local correto, permitindo que usuários insiram uma descrição e carreguem uma imagem do local do dropoff. O backend irá utilizar a OpenAI API para verificar a compatibilidade entre a descrição e a imagem, retornando uma mensagem de 'Valid' ou 'Invalid'.

---

### User Stories:

1. **História do Usuário:**
   - **Como um usuário**, eu quero inserir uma descrição do local onde o pacote foi deixado para que eu possa verificar sua validade.
     - **Critérios de Aceitação:**
       - O sistema deve ter uma caixa de texto onde o usuário possa descrever o local.
       - O texto deve ser aceito tanto em formato curto quanto longo.

2. **História do Usuário:**
   - **Como um usuário**, eu quero carregar uma imagem do local onde o pacote foi deixado para que o sistema possa fazer a validação.
     - **Critérios de Aceitação:**
       - O sistema deve permitir o upload de arquivos nas extensões .png, .jpeg, .jpg e .webp.
       - O sistema deve mostrar um botão para visualizar a imagem carregada.

3. **História do Usuário:**
   - **Como um usuário**, eu quero executar a verificação para saber se a descrição corresponde à imagem carregada.
     - **Critérios de Aceitação:**
       - Deve haver um botão para executar a verificação.
       - A resposta do sistema deve ser claramente mostrada como 'Valid' ou 'Invalid'.

4. **História do Usuário:**
   - **Como um usuário**, eu quero ver a explicação sobre a análise feita para entender a decisão do sistema.
     - **Critérios de Aceitação:**
       - O sistema deve ter um botão para expandir e recolher a explicação fornecida pelo modelo de linguagem.

---

### Funcionalidades Frontend:
- Título do aplicativo: **Dropoff Detection System**
- Caixa de texto para inserir a descrição do local onde o pacote foi deixado.
- Botão para carregar a imagem do local onde o pacote foi deixado.
- Botão para visualizar a imagem carregada na tela.
- Botão para rodar a verificação da imagem em relação à descrição.
- Mensagem de retorno 'Valid' ou 'Invalid' devidamente destacada.
- Botão do tipo expandir/recolher para visualizar a explicação dada pelo LLM.

---

### Funcionalidades Backend:
- Programação em **Python** utilizando **FastAPI**.
- Receber mensagens de texto e imagens enviadas pelo frontend.
- Realizar o encoding da imagem usando base64.
- Integrar com a **OpenAI API** utilizando o modelo **gpt-4o**.
- Respeitar as regras de verificação da imagem conforme estabelecido no prompt.
- Implementar boas práticas de programação, organizando o código em funções modulares e comentando adequadamente.
